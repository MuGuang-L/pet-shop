# 门店信息

服务侧在“店铺设置”维护地址、联系电话、营业时间、自提说明、外送范围、预计送达时间及费用。小程序侧“个人中心 → 联系商家”读取同一份设置；自提结算页同时展示自提说明。

金额以元展示，外送起送金额与免外送费门槛分别说明。关闭自提或外送后，信息页显示“暂未开放”，结算继续遵循原有服务端校验。外送预计时间仅为门店设置的参考值。

订单中的自提地址保留创建订单时的快照。门店信息页显示当前设置，已下单的顾客应按订单详情中的门店信息提货。

设置版本为 0 时明确提示正在使用示例资料，请勿实际到店或寄件。信息刷新失败时显示可能过期的提示。售后入口说明只描述现有申请、审核、退货流程，不替商家承诺尚未提供的售后条款。当前仍是模拟环境，不发生真实支付或退款。

这次调整没有新增接口、修改数据库结构或变更下单协议。小程序登录页改为居中且可滚动的表单，密码输入支持键盘完成操作。

## 验证情况

- 动态费用、自提说明、履约开关及免外送费门槛在页面控制器回归中验证。
- 完整 211 项测试通过，包括独立 MongoDB 三方闭环；共享商品、订单、地址及库存流水保持原状。
- 实际微信开发者工具确认登录页布局，官方 WXML/WXSS 编译通过。
- 门店信息弹层仍需买家手动登录后实际点击验收。实际门店资料、正式隐私说明和售后条款待经营方提供，不能把示例资料当成上线资料。
