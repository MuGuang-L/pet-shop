# 买家与商家退款操作

本次代码增加自定义充值和堂食，简化结算，并统一显示“申请退款”。需同时更新云托管服务、商家后台和小程序后生效；以下为本次代码的操作路径，不代表线上已发布。

## 买家怎么申请

1. 小程序“我的 → 我的订单”，找到订单，点击“申请退款”。订单详情里也有同名入口。
2. 填写原因，确认并提交。待审核期间可以撤回；被拒绝后可以看审核意见，再沟通或重新申请。
3. 在订单详情查看处理进度。退款完成前不要将“商家已同意”理解为已到账。

堂食、自提、快递和会员充值都支持申请。未付款订单直接取消；已退款订单不再重复退款。

| 订单情况 | 申请与处理 |
| --- | --- |
| 堂食或自提，交付前 / 交付后 | 默认仅退款，由商家审核；交付完成仍保留申请入口 |
| 快递未发货 | 仅退款 |
| 快递已发货或已收货 | 可选仅退款或退货退款；仅退款需商家确认无需退货 |
| 会员充值已到账 | 整笔充值退款；审核时扣回本笔到账余额，包含赠送余额。可用余额不足时审核不会通过，需要联系门店核对，不能直接超额退款 |

当前按整单退款，含原快递费；暂不支持部分商品或部分金额退款。退货寄回运费由双方沟通。

## 商家怎么把钱退回去

1. 登录商家 Web 后台，进入“订单 → 查看退款申请”，或点击“退款 / 售后”待办。
2. 打开订单，查看申请原因、金额和原付款渠道，只需选“同意退款”或“不同意”。不再填写审核意见、商品数量、可售数量或额外确认框。
3. 仅退款点击同意后，系统自动提交原渠道退款。微信结果可能需要等待，到账后显示“已退款”；余额支付立即退回本店余额。
4. 退货退款点击“同意退货退款”后，系统提供经营设置中的门店联系人、电话和地址供买家寄回。商家无需每单重填。门店资料缺失时会提示先完善经营设置。
5. 收齐退货后点击“已收齐退货，同意退款”，系统自动提交退款。没有寄回时不能提前执行收货退款。
6. 提交失败或结果待确认时，重新打开订单，点击退款重试入口。审核记录和原退款单号会保留，重试不会重复扣回余额或重复退款。

不同意时订单恢复之前状态，买家可以联系门店或重新申请。同意不代表微信已到账，应以最终退款状态为准；整个正常流程无需再手动点第二次“提交微信退款”。

退款和商品库存调整分开处理。简化审批不会自动回补库存，避免将已制作餐品、破损物品或运输中的商品当成可售库存；可重新销售的商品在商品库存管理中调整。收货按钮表示商家已收齐本单退货，未收齐或有争议时先联系买家。

充值退款自动扣回本笔到账余额（包含赠送）。余额不足时整笔退款会被阻止，不会超额退钱；目前尚不支持部分金额退款。

商家主动取消履约的既有入口仍保留：已付款未完成订单详情 → “遇到缺货或配送问题？” → 登记问题 → “无法继续履约，发起整单退款”。这个异常处理入口沿用原有库存核对步骤；用户主动申请退款使用上面的简化审批。

## 结算与充值约定

- 方式顺序：堂食、到店自提、快递配送；初始默认堂食。
- 堂食立即取单，不提供预约；自提默认立即取单，可点击“预约时间”改选日期和时间。
- 结算页移除门店地址大卡片；快递保留紧凑的收货地址入口。联系电话用于联系和交付。
- 充值入口固定显示 50 / 100 / 200 / 300 / 500 元及自定义金额卡片。自定义金额限制在 0～5000 元，最多两位小数；发起支付须大于 0 元，最低 0.01 元，按实付金额到账。已有固定档位的赠送规则保留，未配置的固定金额按实付金额到账。
- 堂食与自提共用现有“到店自提”接单开关。关闭该开关会同时关闭两种到店订单。
