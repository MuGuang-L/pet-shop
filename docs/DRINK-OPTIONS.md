# 饮品自定义选项

咖啡和饮品支持商家自定义选项组，例如温度、糖分、奶或其他搭配。名称和内容均可编辑，无需把所有搭配展开为不同商品规格。杯型等原有 SKU 规格继续保留。

商家后台打开「商品 → 新增 / 编辑商品」，在「饮品自定义选项」中添加分组与选项。每个选项可设置每杯加价，0 表示不加价；温度、糖分提供可编辑的快捷模板。每组单选，第一项默认选中。每件商品最多 8 组，每组 1～12 项。

用户在商品详情选择搭配后，页面更新单价。同款不同搭配在购物车分行显示，可点击「改搭配」修改；相同搭配合并数量。结算页、买家订单与商家订单详情均展示所选内容。

计价规则：当前普通价或会员价，加上所有所选项的加价。会员资格仍按可用储值余额大于 0 判断，加价本身不额外打折。例如普通价 20 元、会员价 16 元、燕麦奶加 3 元，普通用户支付 23 元，会员支付 19 元。

服务端校验分组及选项编号，从当前商品配置读取加价，忽略客户端提交的名称或价格。报价和创建订单都校验选择与总金额；配置变化导致旧选项失效时，需重新选择。订单保存搭配名称、加价和最终单价的快照，后续编辑商品不改变历史订单。退款按原订单金额处理，包含当时支付的选项加价。

需同时更新云托管服务、商家后台和小程序，无需清空数据或重新导入商品。已有商品默认没有自定义选项，更新代码后由商家按实际菜单配置；本次开发不会自动修改线上商品。
