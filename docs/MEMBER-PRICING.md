# 商品会员价

## 商品设置

商家后台“商品 → 新增 / 编辑 → 规格、价格与库存”可以为每个规格填写普通价和会员价。

会员价默认与普通价相同，未单独指定时会跟随普通价修改；老板单独指定后保留该会员价。留空保存也会按普通价写入。金额范围沿用商品价格限制：0.01～100000 元，最多两位小数。

历史商品没有会员价字段时，按普通价处理，无需先修改所有商品。复制商品会保留两种价格。

## 谁按会员价结算

**当前可用储值余额大于 0 的用户是会员。余额为 0 时，新订单恢复普通价。**

- 仅绑定手机号、打开会员中心或创建未付款充值订单，不会获得会员价。
- 不要求余额足够支付整单；即使有少量余额，也可按会员价下单，再用微信支付。
- 支付方式不改变价格资格；微信与余额支付都使用订单已确定的金额。
- 充值退款占用 / 扣回的余额不再视为可用余额。商品退款退回余额后，如余额重新大于 0，新订单再次享会员价。
- 店铺关闭充值入口，不影响已有可用余额用户的会员计价。

## 结算与订单

商品详情、购物车和结算页按当前身份展示价格。提交前后端重新检查账户余额，使用数据库中的商品普通价 / 会员价计算；忽略客户端提供的身份、单价和总价。

运费减免门槛、起送金额按实际商品成交价计算。确认报价后余额或价格发生变化、导致总额不同，下单会被拒绝并提示重新结算，不会静默创建错价订单。

创建成功的订单保存成交单价、普通价、会员价和当时的会员计价状态。老板之后修改商品价格，或用户余额变化，都不会重算已经创建的订单。订单付款和退款始终按该订单金额处理。

## 发布与验证

此功能需要同时更新云托管服务、商家后台和小程序。数据保存于现有商品 / 订单 JSON，历史数据按缺省规则兼容，不需要批量改价。

自动测试覆盖字段默认值与校验、正余额会员、零余额普通用户、账号隔离、身份与价格伪造、报价后余额变化、原订单价格快照、余额支付及退款、运费门槛，以及商家编辑和小程序显示。真实微信支付与真机显示仍需发布前验收。
