# 商家来单提醒

商家登录 Web 后台后，视觉提醒自动开启。检测到新的已付款、待备货订单时，显示页面内提醒、自提和快递数量，并可点击打开订单。待付款订单不提醒，已备妥的自提订单不计入待备货。

- 提醒显示当前待备货笔数，约 8 秒后自动收起（正在操作提示框时保留）；备好自提或登记发货后数量立即更新。模拟支付订单会标注未扣款测试单。
- 前台约每 20 秒检查一次，后台标签页约每 60 秒尝试检查。浏览器休眠、网络中断会延迟，不能保证即时送达。连接失败会显示重试提示。
- 店员可点击“开启提示音”，允许浏览器播放声音。刷新或重新登录后需要再次开启；视觉提醒不需要点击。
- 在订单页没有编辑或输入时，新单会自动刷新列表；填写表单时只提醒，不自动跳页。
- 已提醒记录保存在当前浏览器，按商家账号区分。刷新通常不重复提醒；换设备、清除浏览器数据会再次提示。多标签页尽量避免重复，但不保证同时检测时只弹一次。
- 首页可输入 6 位提货码查找自提订单，核对商品后点击确认核销；不会自动核销。
- 关闭提醒框不代表接单、备货或完成订单。退出登录停止检查；关闭后台后没有微信推送或系统通知。

部署新版云托管服务后刷新商家后台生效，本功能本身不需要重新上传小程序。后台持续打开会定期访问服务和数据库，可能影响云服务自动休眠及用量。

验证使用隔离模拟订单完成页面内提醒、待办数量、提示音按钮状态和刷新去重检查；未验证真实设备扬声器输出或生产来单。
